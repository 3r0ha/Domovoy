## Что не подтвердилось или спорно

- Доля заявок, подаваемых по телефону, и доля повторных звонков «узнать статус» в открытых источниках не публикуются. Утверждение поставщиков диспетчерских систем о том, что один пропущенный звонок даёт два-три повторных, на открытой странице [MDO](https://mdo.mobi/blog/kak-dispetcherskaya-sluzhba-zhkx-sokrashhaet-vremya-obrabotki-zayavok) цифрами не подкреплено; это редакционная статья без данных. Косвенный показатель: 7,8% коллективных обращений в Госуслуги.Дом.
- Доля жильцов, не передающих показания вовремя, и доля начислений по среднему и нормативу не найдены ни у Росстата, ни у расчётных центров. Есть только абсолютные цифры передач через Госуслуги.Дом (30 млн).
- Утверждение СМИ о том, что при непередаче показаний три месяца применяется норматив с коэффициентом 3 ([Мойка78](https://moika78.ru/news/2026-05-05/1297823-trojnoj-udar-po-koshelku-s-1-maya-nachali-dejstvovat-novye-pravila-peredachi-pokazanij-schetchikov/)), не совпадает с письмом Минстроя от 17.03.2026: коэффициент 3 применяется при отсутствии ИПУ холодной воды. В п. 59-60 ПП 354 повышающий коэффициент при непередаче показаний не предусмотрен. Использовать только формулировку про отсутствие счётчика.
- Число проверенных номеров АДС по стране и доля неподтверждённых на федеральном уровне не опубликованы; есть только региональные сводки по Татарстану с разными цифрами в июне (624 в Казани) и августе (555 в Казани) 2026, вероятно, по разным раундам проверки.
- Средняя продолжительность ожидания ответа диспетчерской в минутах в открытых источниках отсутствует; есть только норматив.
- Доля домов с электронными собраниями через ГИС ЖКХ не публикуется; известна лишь доля собраний, проведённых в приложении (37%), без числа домов. Опрос администраторов ГИС ЖКХ на 32 человек не репрезентативен.

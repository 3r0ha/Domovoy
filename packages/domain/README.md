# @domovoy/domain

Правила продукта: чистые функции и типы, без базы, HTTP и платформы. Одни и те же правила
работают в чате и в приложении.

## Что внутри

| Файл | О чём |
|---|---|
| `types.ts` | Заявка, роли, объекты адресации, вложения |
| `status.ts` | Жизненный цикл: кто вправе выполнить переход и где нужно объяснение |
| `sla.ts` | Сроки реакции и выполнения, просрочка, предупреждение до срыва, прогноз |
| `incident.ts` | Склейка обращений: когда повтор считается той же аварией |
| `works.ts` | Плановые работы: когда обращение объясняется объявленным отключением |
| `audience.ts` | Кого касается: дом, подъезд, стояк, квартира, оборудование |
| `broadcast.ts` | Адресат рассылки: от дома до перечисленных квартир, должники, не подавшие показания |
| `deep-link.ts` | Коды объектов для наклеек и ссылок `?start=` / `?startapp=` |
| `stickers.ts` | Что и куда клеить: подъезды и стояки по квартирам, стили и своя надпись |
| `helpdesk.ts` | Обращение в поддержку: состояния переписки и порядок в очереди |
| `meters.ts` | Приборы учёта: приём показаний, расход, резкий скачок |
| `analytics.ts` | Сводка по дому за период: качество исполнителей, проблемные объекты |
| `voting.ts` | Собрание собственников: кворум и голоса по долям площади |
| `request.ts` | Заведение заявки: номер, сроки, подсказка категории и срочности |
| `escalation.ts` | Основание для обращения в жилищную инспекцию и его текст |
| `inspection.ts` | Осмотры общего имущества и плановое ТО оборудования по регламенту |
| `billing.ts` | Квитанция из показаний и тарифов дома |
| `norms.ts` | Расчёт без показаний: три месяца по среднему, дальше по нормативу |
| `common.ts` | Общедомовые нужды: разница с суммой квартир по площади |
| `penalty.ts` | Пени за просрочку по ст. 155 ЖК РФ |
| `wear.ts` | Как часто объект ломается и когда ждать следующего раза |
| `duty.ts` | Рабочие часы и дежурство: кому уходит ночная заявка |
| `mood.ts` | Состояние дома одним словом: спокоен, просрочка, авария |
| `moment.ts` | Даты и сроки словами, по часовому поясу дома |
| `russian.ts` | Деньги, площади и числа со словом в нужном падеже |
| `numbers.ts` | Округление денег, медиана и промежутки времени |

## Чего здесь нет

Ни одного `await` к базе, ни одного упоминания Fastify или Bot API. Правила настраиваются
под конкретную управляющую организацию, поэтому они лежат отдельно от обработчиков.

## Что настраивается без правки кода

Нормативы у каждой управляющей организации свои, поэтому пороги и таблицы вынесены в константы
и экспортируются наружу:

| Что | Константа |
|---|---|
| Сроки реакции и выполнения по категориям | `CATEGORY_RULES` |
| Насколько срочность сжимает срок | `PRIORITY_FACTOR` |
| Когда предупреждать о подходящем сроке | `WARNING_SHARE` |
| Какие категории считаются общим имуществом | `SHARED_INFRASTRUCTURE` |
| Окно склейки обращений | `JOIN_WINDOW_HOURS` |
| Со скольких обращений авария считается подтверждённой | `CONFIRMED_INCIDENT_REPORTERS` |
| Со скольких заявок объект попадает в отчёт | `PROBLEM_OBJECT_THRESHOLD` |
| Насколько нужно превысить срок, чтобы жаловаться в ГЖИ | `ESCALATION_OVERRUN_FACTOR` |
| Через сколько молчание закрывает заявку и когда напомнить | `AUTO_CONFIRM_AFTER_HOURS`, `ACCEPTANCE_REMINDER_SHARE` |
| Окно подачи показаний и порог скачка расхода | `READING_WINDOW`, `SPIKE_FACTOR` |
| Сколько месяцев считать по среднему и за какой срок его брать | `AVERAGE_MONTHS`, `AVERAGE_WINDOW` |
| Нормативы потребления и повышающий коэффициент | `NORM_PER_PERSON`, `NORM_PER_AREA`, `NORM_FACTOR` |
| С какого дня и по какой доле ставки идут пени | `PENALTY_FREE_DAYS`, `PENALTY_SOFT_UNTIL_DAY` |
| Пороги и база подсчёта на собрании | `POLL_RULES` |
| Кто какой переход может выполнить | `TRANSITIONS` |
| Часовой пояс дома | `DEFAULT_TIME_ZONE` |

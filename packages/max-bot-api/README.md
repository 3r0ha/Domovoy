# @maxkit/max-bot-api

Форк официального [`@maxhub/max-bot-api`](https://github.com/max-messenger/max-bot-api-client-ts)
от версии 0.3.0.

Библиотека сама по себе зрелая: композиция обработчиков, фильтры, сценарии и сессии сделаны
хорошо, и переписывать их незачем. Всё, что можно закрыть снаружи, закрыто отдельными
пакетами `@maxkit/*` через публичные точки расширения. Здесь, только те дефекты,
у которых точек расширения нет.

Происхождение, полный список изменений с ссылками на места в коде и на открытые issues,
а также то, что намеренно оставлено как есть, в [`UPSTREAM.md`](UPSTREAM.md).

Лицензия исходной библиотеки MIT сохранена в [`LICENSE`](LICENSE); авторы исходного кода,
команда MAX.

## Тесты

```bash
npm test --workspace @maxkit/max-bot-api
```

53 теста: перенесённые из апстрима плюс проверки на наши изменения, отличие от оригинала
должно быть видно тестом, а не только текстом в UPSTREAM.md.

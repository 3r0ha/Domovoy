# @domovoy/app

Сценарии продукта, общие для чат-бота и мини-приложения. Правила берутся
из `@domovoy/domain`, данные из хранилища за интерфейсом `Repository`.

Бот и приложение вызывают отсюда одни и те же функции, поэтому поведение в переписке
и в приложении совпадает.

## Зависимости наружу

Снаружи передаются три зависимости: часы, генератор идентификаторов и канал уведомлений.
Часы позволяют проверять сроки на фиксированном времени. Канал отвечает за отправку,
а кого известить, решает прикладной слой.

Уведомление несёт текст и список доступных получателю переходов: какие переходы возможны,
знает предметная область, как показать их кнопками, решает канал.

# @maxkit/devhost

Стенд для мини-приложения MAX: приложение работает в iframe, а роль клиента мессенджера
играет эмулятор из [`@maxkit/bridge/mock`](../bridge).

Нужен потому, что Bridge отвечает только внутри клиента MAX, а получить токен бота нельзя
без верифицированного профиля организации. Стенд отвечает по тому же протоколу, поэтому
приложение не меняется: никаких веток «если разработка».

## Сборка стенда

```ts
import { createStand } from '@maxkit/devhost';

const stand = await createStand({
  container: document.body,
  appUrl: 'http://localhost:5173',
  botToken: process.env.BOT_TOKEN,          // параметры запуска будут подписаны настоящим HMAC
  client: { startParam: 'lift_1234', platform: 'ios', latencyMs: 150 },
});
```

Приложение открывается по своему обычному адресу с параметрами запуска в hash, так же,
как его открывает клиент MAX. Если передан токен бота, подпись настоящая, и локальная разработка
проходит боевую серверную проверку `initData`.

Приложение при этом должно доверять origin стенда, только в dev-сборке:

```ts
import { getBridge, LOCAL_DEV_ORIGINS } from '@maxkit/bridge';

const bridge = getBridge(import.meta.env.DEV ? { trustedOrigins: [...LOCAL_DEV_ORIGINS] } : {});
```

## Панель

Панель показывает то, чего не видно из самого приложения:

- параметры запуска: пользователь, платформа, версия, `start_param`;
- состояние клиента: сообщило ли приложение о готовности, показана ли кнопка «назад»,
  включено ли подтверждение закрытия, разрешены ли свайпы и снимок экрана, какие ссылки открывались;
- содержимое обычного и шифрованного хранилищ;
- ленту событий в обе стороны, что приложение отправило и что клиент ответил.

Действия: нажать системную кнопку «назад», перезапустить приложение с теми же параметрами,
очистить ленту. Перерисовка происходит только при изменениях, чтобы панель не мешала отладке.

## Ядро без интерфейса

`DevHost` можно использовать отдельно от панели, например, в автотестах интерфейса:

```ts
const host = await DevHost.create({ appUrl, client: { startParam: 'lift_1234' } });
const detach = host.attach(channel);   // любой канал, не обязательно iframe

host.client.pressBackButton();
host.state.deviceStorage;              // что приложение записало
host.log;                              // лента событий
```

## Тесты

```bash
npm test --workspace @maxkit/devhost
```

15 тестов: сборка адреса запуска и подпись параметров, ответы по протоколу, доставка событий
в приложение, отключение канала, отсев посторонних сообщений в канале, а также рендер панели,
её кнопки и очистка.
